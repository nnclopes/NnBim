NnBim Ferramentas: InPlace para RFA
DESCRIÇÃO:
Substitui elementos In-Loco ou DirectShapes por instâncias de Famílias Carregáveis (.rfa).
O script calcula automaticamente o ponto de inserção, a rotação e a altura da peça original,
criando novos tipos de família se a altura for diferente.

COMO USAR:
1. Primeiro, use a ferramenta 'Explodir InPlace' para separar as peças.
2. Selecione as peças soltas no Revit.
3. Execute esta ferramenta.
4. Escolha a família de destino e o parâmetro que controla a altura (ex: 'Altura').
5. O script substituirá as peças e ocultará as originais para conferência.
