NnBim Ferramentas: Explodir InPlace (Dinâmico)
DESCRIÇÃO:
Explode elementos In-Loco complexos em peças individuais (DirectShapes).
Diferencial: Permite trocar a categoria das peças geradas durante o processo (ex: transformar um In-Loco de 'Modelo Genérico' em várias peças de 'Marcenaria').

COMO USAR:
1. Selecione a Família In-Loco.
2. Escolha a categoria de destino para as novas peças.
3. Confirme a explosão. O original será deletado e substituído pelas partes soltas.
